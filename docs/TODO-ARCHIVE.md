# 已完成事项

## 0.2.2

- 镜像模式会把移出导入范围的笔记、无引用的图片和手动放入同步目录的文件移到同级备份目录。例如，`Attachments/Backup/minote` 对应 `Attachments/Backup/minote-delete`。
- 每次清理单独保存并保留原有子目录。导入结果会显示移出的文件数量和本次备份路径。

## 0.2.1

- 在 Obsidian 的「小米笔记」标签页登录并完成设备验证。导入会等待验证通过后自动继续。
- 增量和全量导入都可以按创建日期和小米云文件夹限定范围，同时设置时取两者的交集。
- 导入时同步云端标题和分类变更。默认的「镜像模式」在当轮导入无失败或待补项时，会将云端已删除或移出导入范围的已导入笔记移至笔记库回收站，并清理已登记且无引用的图片和已经为空的旧分类目录。「复制模式」会保留云端已删除或移出范围的已导入笔记。
- 修复部分 Markdown 笔记导入后仍使用小米云图片地址的问题。升级后会重新检查受影响的历史导入记录。
