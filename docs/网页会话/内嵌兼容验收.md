## 图片引用问题与处理

首次验收下载了图片，但部分 Markdown 仍引用小米内部图片地址。原因是旧转换仅识别 XML/fileId 占位符，而 Markdown 地址使用附件摘要。附件清理可能因此误认为下载的图片未被引用。

已按摘要增加转换、将残留地址计入图片待补检查，并为旧导入记录增加重新检查机制。修复后实际读取的 48 个本地图片引用均能找到文件，自动回归覆盖正常转换、下载失败和旧记录升级。

## 清理与异常保护

- 当前 Obsidian 的非递归目录删除调用使用 `fs.rm`，传入目录会失败。改用仅能删除空目录的 `fs.rmdir`，并检查实际路径；用系统临时目录验证空目录可移除、有文件的目录会保留。
- 离线检查覆盖等待设备验证后自动继续、请求未完成时取消、账号变化和异常清单制止清理，以及待解密或图片不完整时保留本地文件。接口返回限流或服务不可用时停止后续请求。
- 本次真实账户未单独确认未加密正文、未分块普通图片的样本。普通正文及旧图片引用规则有离线回归；等待中的任务跨真实登录自动继续及清理修正后的整体验收没有再次使用真实账号复测。
