# 网页会话

## 职责

`MinoteView` 自行创建小米笔记标签页；`MinoteWebSession` 管理页面、账号检查、等待验证、正文和图片读取。官网提供编辑能力，插件不实现云端编辑协议。

## 当前实现

- 专用会话名称由笔记库完整路径与域名的摘要生成，不与其他笔记库或系统浏览器共享登录。
- 网页关闭时保留会话，重新打开可复用登录。退出登录清除当前专用会话，保留本地笔记与导入记录。
- 账号检查区分认证有效、明确未登录、暂时不可用。空闲时只检查本地会话是否变动，导入等待中也限制账号请求频率。网络异常保留上次确认状态；云端拒绝、限流或服务异常时中止导入。
- `ensureReady` 最多等待五分钟，检查官方笔记页面、已显示的笔记列表及设备验证状态。登录导航期间继续等待；就绪后返回固定会话快照。
- `readEncryptedNote`、`readImage` 通过对应 `webContents.debugger` 执行已有网页读取逻辑，普通图片沿用浏览器网络资源读取，分块图片由官网模块下载与解密。

## 必须保持的约束

- 不把网页 Node 权限打开，不关闭网页安全检查，不增加外部浏览器备用模式。
- 网页生命周期与导入控制分开：切换标签页不取消；关闭、重新加载、账号或域名改变后，不继续使用旧任务快照。
- 每次正文、图片读取前后核对会话；取消后的迟到响应不能继续写文件。任务结束后移除本轮认证快照和取消信号。
- 不输出认证凭据、设备验证码、加密密钥或整份接口返回。
- 新增宿主相关调用必须通过当前 Obsidian 实测，不能以普通 Chrome 验证代替。
