# 技术架构

Minote Importer 提供小米官方笔记网页的桌面内嵌入口，并将当前账号的笔记单向导入 Obsidian。网页编辑由官网保存到小米云；插件没有本地 Markdown 回写接口。

## 模块与边界

| 模块 | 职责 | 入口文档 | 主要代码入口 |
| --- | --- | --- | --- |
| 网页会话 | 标签页、账号校验、设备验证、网页解密及图片读取 | [网页会话](网页会话/README.md) | `src/minoteView.ts`、`src/minoteWebSession.ts`、`src/webNote.ts` |
| 导入 | 清单分页、增量记录、分类转换、导入取消及清理调度 | [导入](导入/README.md) | `main.ts`、`src/minoteApi.ts`、`src/noteSyncer.ts`、`src/importControl.ts` |
| 本地文件 | 保存目录约束、文件读写、图片引用检查及回收站操作 | [本地文件](本地文件/README.md) | `src/fileManager.ts`、`src/noteProperties.ts` |

`src/settings.ts` 保存非敏感配置和导入记录，并提供只在内存中存在的请求认证状态；设置界面由 `src/settingTab.ts` 呈现。

## 主要数据流

1. 左侧图标打开或复用小米笔记标签页；导入命令额外启动一轮任务。
2. `MinoteWebSession.ensureReady` 等待官方账号认证与设备验证完成，取得本轮会话快照。
3. `MinoteApi` 固定使用该快照读取清单和正文；加密正文、分块图片及需要浏览器会话的普通图片由内嵌页读取。
4. `NoteSyncer` 转换正文、下载图片、更新分类；`FileManager` 在每次落盘前检查任务仍有效。
5. 完整读取云端清单、处理结束且会话未改变时，执行现有受归属保护的删除清理。取消或会话失效跳过后续清理，保存已完成和未处理的导入记录。

## 状态与存储归属

- 官方登录及解密资料归专用持久化浏览器会话所有，会话按笔记库完整路径和小米服务域名隔离。
- 插件配置只保存账号显示状态、昵称、路径、导入记录及结果；认证凭据不写入插件数据或日志。
- 本轮任务固定账号、服务域名和保存路径；本地记录同时保持账号和目录归属约束。
- 页面加载、等待验证和导入进度属于任务状态；账号只呈现已登录、未登录两种状态，网络错误不直接等同退出登录。

## 设计约束

使用插件自建 `ItemView` 与隔离 `webview`，不依赖核心“网页查看器”、系统 Chrome 或外部调试端口。Electron 宿主访问集中在网页会话模块，不修改 Obsidian 本体、不降低网页安全配置。

完整兼容性验证与历史问题见[内嵌兼容验收](网页会话/内嵌兼容验收.md)。
