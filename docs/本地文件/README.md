# 本地文件

`FileManager` 接收固定保存目录，不允许历史相对路径越出该目录。所有创建、移动、写入和回收站操作在实际执行前检查任务仍有效。

笔记保存为 Markdown，属性由 `noteProperties.ts` 管理；保留原有创建时间、修改时间以及非插件属性。分类与笔记同名时分配独立路径，不覆盖其他笔记或自行创建的文件。

删除仅处理可确认账号、路径和笔记编号归属的导入文件，并使用回收站。先验证分类目录真实路径仍在笔记库内，再调用只允许删除空目录的文件系统操作。正文或下载不完整时，整轮跳过清理。

取消已发出的单个文件操作不能保证撤回；操作完成后保留对应记录，并阻止后续写入或删除。不得通过强制中断文件操作破坏已有正文。
