# 导入与本地对齐

## 职责与入口

- `main.ts`：网页入口、增量和全量导入任务、进度和结果展示、保存最终导入记录。
- `src/noteSyncer.ts`：完整清单分页、旧编号迁移、正文与图片处理、标题和分类对齐、清理已移出导入范围的文件。
- `src/minoteApi.ts`：小米云接口；每次读取固定域名和登录会话。设置页和导入共用分页校验。
- `src/importOptions.ts`：创建日期区间及文件夹选择校验。
- `src/fileManager.ts`：保存目录边界校验、文件读写和移动、同级备份目录、图片引用检查与非递归空目录清理。
- `src/settings.ts`、`src/models.ts`：持久化导入记录和移动检查点。
- `src/noteProperties.ts`：写入或更新笔记属性，保留已有的自定义属性。

## 数据流程

1. 导入开始时固定保存目录、导入模式和范围。打开或复用内嵌网页，自动等待登录与设备验证，再固定接口会话。仅复用当前完整保存目录下属于当前账号或尚未登记账号的历史记录。
2. 分页获取完整笔记和分类清单。分页中断、标记异常、未知条目类型、重复或非法笔记 ID、缺失分类时，停止导入，不执行清理。
3. 按创建日期和文件夹的交集筛选。开始日期从北京时间零点起算，结束日期包含当天。只有完整清单校验通过后才筛选和写入。使用小米云提供的 `v3SyncId` 迁移范围内笔记的旧编号，以云端笔记 ID 关联本地相对路径。
4. 增量导入以修改时间、本地文件存在性、解密和图片补齐状态决定是否读取正文。即使跳过正文，也检查标题、目标路径并更新属性。全量导入重新读取范围内的所有正文，两者共用移动与写入流程。
5. 镜像模式下，本轮完整处理且无待解密、图片待补或失败项时，扫描所选同步目录。保留本轮范围内笔记和明确属于其他账号的导入文件，把其余笔记及手动文件移到同级的 `<目录名>-delete`，按批次保留原相对路径。移动失败保留记录以便重试，文件已不存在时清理对应记录。复制模式保留这些文件及导入记录。
6. 笔记和其他文件成功移出后，检查受管理图片及 `img` 目录中的旧图片在现有 Markdown 笔记中的引用。无引用的图片移到同批备份。最后以非递归方式移除空的旧分类目录。

## 状态归属与约束

- 导入记录仍使用 `SyncInfo`：`note` 保存 ID 与本地路径，`folder` 保存已创建的分类路径；新增 `image` 记录保存受管理图片路径。
- `account` 是域名与稳定账号编号的 SHA-256 摘要，不记录原始账号编号或额外登录凭证。无法提取稳定账号编号时禁止清理；会话切换后也禁止本轮清理。
- 镜像模式需要选定笔记库内的子目录，扫描与移动前核对实际路径。每个清理批次独立存放，同名文件留在各自原子目录或清理批次内。同步目录中的手动文件也会被移出。
- 移动沿用原有 `pendingMove` 检查点。如果旧路径已不存在、待移动路径存在，恢复实际文件路径，并依据已登记的源图片恢复目标图片归属；两个位置均存在时保留并报告失败。
- 文件夹选择以账号摘要和小米云文件夹 ID 保存。文件夹改名不影响选择。打开小米笔记并登录后，可在设置中读取文件夹列表。切换账号后，旧的文件夹限制需要重新选择或清除。
- 旧版本无账号记录：范围内的笔记通过云端 ID 补齐账号。镜像中已移出范围的旧笔记仍可备份，缺少账号归属或属性编号不会阻止移动。
- 图片清理直接读取笔记库磁盘上的 Markdown，排除当前镜像备份目录、回收站、配置目录和 `.git`，避免文件索引延迟漏掉引用。插件生成的 `img/` 引用按相对路径解析；其他 Markdown、双链或 HTML 等内容出现候选图片文件名时保守保留。扫描读取失败时保留图片。
- 写入或解密失败保留原笔记和导入记录。失败的图片清理及未移除的旧分类记录继续保留，下次导入重试。
- 取消、页面失效或账号变化必须中止后续写入和清理，保留已完成及未处理记录。取消检查不应被逐篇失败捕获后吞掉；实际文件操作前再次核对任务。
- 普通笔记范围继续排除私密笔记；已导入的笔记移入私密范围后，与移出普通笔记清单一样处理。

## 验证

- `npm test` 使用真实导入类和内存笔记库验证：两种模式完整分页、云端空清单、删除、无时间变化的改名、分类移动、同名分类和笔记、缺失文件恢复、图片共享与清理、账号切换、旧编号迁移、移动中断、备份移动失败及目录边界。
- 导入范围的模拟测试覆盖日期边界、多选文件夹与未分类、零匹配、镜像及复制模式切换、备份手动文件和旧记录、复制模式保留文件、失效的范围设置、异常创建时间、账号切换和文件夹分页读取。
- `npm run build` 检查类型并生成插件构建。
- 真实宿主验证结果见[内嵌兼容验收](../网页会话/内嵌兼容验收.md)；模拟检查和构建成功不能替代实际导入、图片引用或镜像备份验收。
