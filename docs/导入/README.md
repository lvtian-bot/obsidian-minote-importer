# 导入

## 入口与边界

`main.ts` 统一接收标签页、命令和右键菜单的导入请求，同一时刻仅运行一轮任务。点击左侧图标只打开网页。导入请求固定开始时的保存路径、导入模式和范围，再打开或复用网页并等待验证。

`MinoteApi` 固定请求快照。`importOptions.ts` 验证日期和文件夹选择。`NoteSyncer` 对完整云端清单应用筛选，负责正文转换、增量记录和镜像清理调度。文件操作由本地文件模块完成。完整数据流程和归属规则见[导入与本地对齐](导入说明.md)。

## 图片转换

图片下载成功后才替换正文引用，支持旧 XML 的 fileId、旧占位符，以及 Markdown 的 `com.miui.notes/image/<digest>` 地址。后者按附件摘要匹配，不能用 fileId 直接查找摘要地址。

图片转换记录版本为 2。旧记录必须再次检查正文，修复“图片已下载、Markdown 仍引用小米内部地址”的情况。无法下载或无法匹配的图片标记为待补，后续增量导入重试。

## 任务控制

取消信号、页面销毁或会话变化会中止后续处理；中断不是普通逐篇失败，不能吞掉异常后继续处理其他笔记。保留本轮已完成记录与未处理历史，结果明确显示取消或中断。

镜像清理会把范围外文件移到同步目录同级的 `-delete` 文件夹。备份路径和保留规则见[导入与本地对齐](导入说明.md#状态归属与约束)。待解密、图片待补及失败统计继续保留，不能把不完整导入显示为完成。

回归测试：`npm test`。
