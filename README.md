# Minote Importer

将[小米笔记](https://i.mi.com/note/h5#/)单向导入 Obsidian，保存为 Markdown 文件。可按创建日期和小米云文件夹限定导入范围，支持镜像模式和复制模式。

## 功能
- 在 Obsidian 标签页中登录、浏览和编辑小米官方笔记网页，无需启用“网页查看器”核心插件或安装系统浏览器
- 按文件夹存放笔记，同时保留笔记的创建时间和修改时间
- 自动下载笔记中的图片，并将引用方式替换成 Markdown 格式
- 替换 `<background>` 标签为 `<span>` 标签，以支持文字高亮
- 去除多余的 `<text>`、`<new-format/>` 标签
- 文件名优先使用小米笔记的原始标题。无标题时使用按北京时间计算的创建日期和固定的六位数字，例如 `2026-11-14-482731.md`
- 支持增量导入和全量导入，两者均应用设置中的导入范围和模式
- 支持非中国区的小米云服务

## 安装

1. 在[本项目的 Releases](https://github.com/lvtian-bot/obsidian-minote-importer/releases)下载发行压缩包。
2. 将压缩包内的 `minote-importer` 文件夹放入笔记库的 `.obsidian/plugins/` 目录。
3. 重启 Obsidian，在「设置 → 第三方插件」中启用「Minote Importer」。

如需从源码构建，在仓库目录执行 `npm ci` 和 `npm run build`，将生成的 `main.js` 与 `manifest.json`、`LICENSE` 一起放入 `.obsidian/plugins/minote-importer/`。

## 设置

1. 点击左侧栏的云下载图标打开「小米笔记」标签页，或在插件设置的「小米账号」中点击「登录」。在小米官方页面完成登录和设备验证。
2. 账号区域只显示「未登录」或「已登录 · 昵称」。导入会自动等待验证完成，无需手动确认。
3. 选择笔记保存位置，默认使用笔记库内的 `minote-importer` 文件夹。
4. 在「导入模式」中选择「镜像模式」（默认）或「复制模式」。镜像模式需要选择笔记库内的子文件夹，清理的文件会移到同级的 `-delete` 文件夹。请使用专用同步目录。复制模式只导入或更新范围内的笔记。
5. 在「导入范围」中填写「开始日期」和「结束日期」。按创建日期筛选，以北京时间为准，包含起止当天，留空的一端表示不限。保持登录后的小米笔记标签页打开，点击「读取文件夹」，可勾选多个小米云文件夹及「未分类」。点击「全部文件夹」可取消文件夹限制。笔记须同时符合已设置的日期和文件夹条件。
6. 登录过期后，在小米笔记标签页重新登录。设置中的「退出登录」清除当前笔记库和服务域名的专用网页会话，保留本地笔记与导入记录。

插件使用独立的内嵌网页会话。升级自外部浏览器版本后，需要在内嵌页重新登录一次；旧的认证凭据不会迁移，并从插件配置中移除。

## 使用

- **打开网页**：点击左侧栏的云下载图标，只打开或切换到「小米笔记」标签页。
- **增量导入**：点击标签页工具栏的「导入到 Obsidian」，或执行命令「导入小米笔记」。
- **全量导入**：在工具栏下拉菜单选择「全量导入」，也可使用左侧图标右键菜单或命令「全量导入小米笔记」。

通过命令或右键菜单导入时，插件会自动打开内嵌页；完成登录和设备验证后继续导入。切换到其他标签页不影响任务，关闭小米笔记标签页或点击「取消导入」则停止后续处理，保留已完成结果，下次导入重新检查。

内嵌网页中的编辑直接保存到小米云。导入读取云端已保存的内容，本地 Markdown 不会回写小米。

两种方式都会先分页读取完整的云端清单，再按导入范围筛选。增量导入通常只下载发生变化或需要补齐的正文。全量导入重新读取范围内的全部正文并覆盖对应文件。

导入会覆盖对应的 Markdown 文件，请将需要手动编辑的内容保存在导入目录之外。

已导入的旧文件会在下次导入时应用新的命名规则。

导入以小米云网页版的标题和分类为准。修改标题、新建或重命名文件夹、移动笔记后，下次导入会更新本地文件名和分类。增量导入时，正文未变化的笔记会保留原文件内容，笔记引用的图片会复制到目标分类。升级时，插件使用小米云提供的旧版编号关联已有导入记录。普通笔记导入范围排除小米云的「私密笔记」。

镜像模式会把不再符合导入条件的笔记、无引用的图片和同步目录内手动存放的文件移到备份目录。例如，选择 `Attachments/Backup/minote` 后，文件会移到同级的 `Attachments/Backup/minote-delete`，按清理批次和原有子目录保存。导入结果显示移出的文件数和本轮备份位置。仍被引用的导入图片以及明确属于其他小米账号的导入文件会保留。导入有待解密、图片待补或失败项时，本轮暂缓清理。

旧版本的导入记录可能没有账号归属。范围内的笔记会通过云端 ID 自动补齐归属，已移出范围的旧文件也可以随本轮清理移到备份目录。需要恢复时，可以把文件从相应批次的备份目录移回原位置。实现与验证说明见[导入说明](docs/导入/导入说明.md)。

导出的 Markdown 包含 `title`（标题）、`noteId`（小米云笔记编号）、`category`（小米云分类）、`created`（创建时间）和 `modified`（修改时间）。编号以文本保存，时间使用带 `+08:00` 的 ISO 8601 格式。升级后，增量导入会为仍在云端且正文无变化的笔记补齐或更新这些属性，同时保留正文、图片引用和其他属性。

插件设置中的「导入状态」会显示保存位置、当前进度和上一次结果。已写入正文但图片待补齐的笔记会单独提示，下一次导入会重试。

加密笔记由完成验证的内嵌小米网页解密。对于网页版接口无法按原编号读取的旧版笔记，插件会将原接口返回的正文交给网页解密。图片支持网页返回的分块下载和通过浏览器会话下载的普通图片，并将 Markdown 中按附件摘要引用的小米图片地址替换为本地路径。无法解密或补齐图片时，插件提示待处理数量并保留已有文件，下次导入重试。升级后会重新检查旧版密文文件及未正确替换的图片链接。

## 已知问题

- 登录会话可能过期，可在内嵌小米笔记页面重新登录。
- 遇到网络连接问题时可重试。增量导入会跳过已导入且未变化的笔记。
- 清单不完整、账号归属不明或本地 `noteId` 与导入记录不符时，插件会保留相关文件；不会根据异常响应猜测删除。
