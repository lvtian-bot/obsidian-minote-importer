# Minote Importer

将[小米笔记](https://i.mi.com/note/h5#/)单向导入 Obsidian，保存为 Markdown 文件。首次导入会读取全部笔记，后续默认只更新有变化的正文，同时跟随云端的改名、分类移动和删除。

## 功能
- 按文件夹存放笔记，同时保留笔记的创建时间和修改时间
- 自动下载笔记中的图片，并将引用方式替换成 Markdown 格式
- 替换 `<background>` 标签为 `<span>` 标签，以支持文字高亮
- 去除多余的 `<text>`、`<new-format/>` 标签
- 文件名优先使用小米笔记的原始标题。无标题时使用按北京时间计算的创建日期和固定的六位数字，例如 `2026-11-14-482731.md`
- 支持全量导入，覆盖更新全部正文，并清理云端已删除的对应本地笔记
- 支持非中国区的小米云服务

## 安装

1. 在[本项目的 Releases](https://github.com/lvtian-bot/obsidian-minote-importer/releases)下载发行压缩包。
2. 将压缩包内的 `minote-importer` 文件夹放入笔记库的 `.obsidian/plugins/` 目录。
3. 重启 Obsidian，在「设置 → 第三方插件」中启用「Minote Importer」。

如需从源码构建，在仓库目录执行 `npm ci` 和 `npm run build`，将生成的 `main.js` 与 `manifest.json`、`LICENSE` 一起放入 `.obsidian/plugins/minote-importer/`。

## 设置

1. 在「Minote Importer」的插件设置中点击「打开小米云网页」，在独立 Chrome 或 Edge 窗口里登录。若小米要求设备保护码，请在小米网页完成验证。
2. 完成验证后，等 Obsidian 显示「小米云已登录」。如果网页已能打开笔记正文，插件仍显示等待，请保持网页打开，点「确认已完成验证」。导入加密笔记期间请保持网页打开。
3. 选择笔记保存位置，默认使用笔记库内的 `minote-importer` 文件夹。
4. 登录过期后，重新打开小米云网页并确认登录。点击「退出」可清除此笔记库的插件登录状态和专用浏览器登录数据。

插件使用独立的浏览器配置目录，首次使用需要登录。高级设置可指定浏览器路径。

## 使用

- **增量导入**：点击左侧栏的云下载图标，或在命令面板中执行「导入小米笔记」。
- **全量导入**：右键点击左侧栏的云下载图标，或在命令面板中执行「全量导入小米笔记」。

两种方式都会先分页读取完整的云端清单，按笔记 ID 对齐新增、改名、分类移动和删除。增量导入通常只下载发生变化或需要补齐的正文；全量导入重新读取全部正文并覆盖对应文件，不先清空本地目录。

导入会覆盖对应的 Markdown 文件，请将需要手动编辑的内容保存在导入目录之外。

已导入的旧文件会在下次导入时应用新的命名规则。

导入以小米云网页版的标题和分类为准。修改标题、新建或重命名文件夹、移动笔记后，下次导入会更新本地文件名和分类。增量导入时，正文未变化的笔记会保留原文件内容，笔记引用的图片会复制到目标分类。升级时，插件使用小米云提供的旧版编号关联已有导入记录。普通笔记导入范围排除小米云的「私密笔记」。

云端删除或移入私密范围的笔记，在完整清单读取成功且确认账号、文件身份后，会将对应的已导入 Markdown 移至笔记库的 `.trash` 回收站，并在结果中显示「移至回收站 X 篇」。插件只清理有归属记录且确认无引用的导入图片，以及已经为空的旧分类目录；自行创建的文件会保留。图片仍被笔记库内其他 Markdown 引用时会保留；待解密、图片待补齐或存在失败时暂缓图片清理。

旧版本的导入记录没有账号归属。升级后，云端仍存在的笔记会通过 ID 自动补齐归属；升级前已从云端消失、无法确认归属的旧笔记会保留，并计入检查失败。没有归属记录的历史图片也会保留，后续成功读取对应云端附件时建立记录。实现与验证说明见[导入说明](docs/导入/导入说明.md)。

导出的 Markdown 包含 `title`（标题）、`noteId`（小米云笔记编号）、`category`（小米云分类）、`created`（创建时间）和 `modified`（修改时间）。编号以文本保存，时间使用带 `+08:00` 的 ISO 8601 格式。升级后，增量导入会为仍在云端且正文无变化的笔记补齐或更新这些属性，同时保留正文、图片引用和其他属性。

插件设置中的「导入状态」会显示保存位置、当前进度和上一次结果。已写入正文但图片待补齐的笔记会单独提示，下一次导入会重试。

加密笔记由完成验证的小米云网页解密。对于网页版接口无法按原编号读取的旧版笔记，插件会将原接口返回的正文交给网页解密。图片支持网页返回的分块下载和通过浏览器会话下载的普通图片。如果网页暂时无法解密，插件会提示待导入数量并保留已有文件，完成验证后可以重试。升级后，增量导入会重新检查旧版本写入的密文文件。

## 已知问题

- 登录会话可能过期，可在插件设置中手动刷新。
- 遇到网络连接问题时可重试。增量导入会跳过已导入且未变化的笔记。
- 清单不完整、账号归属不明或本地 `noteId` 与导入记录不符时，插件会保留相关文件；不会根据异常响应猜测删除。
